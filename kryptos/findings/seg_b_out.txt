B1. Constraint accounting: what do the cribs constrain inside a segment?
==============================================================================
A period-p key inside a segment is pinned only where two crib positions of that
segment share a residue mod p.  constraints c = (#crib positions in segment) -
(#distinct residues mod p).  A random key passes with probability 26^-c, so
c = 0 means the test is VACUOUS - every key passes.

B2. LOCAL KEY EXTENSION: key fully determined by one crib run, decrypt outwards
==============================================================================
For a run of L consecutive crib positions and period p <= L every residue class
mod p contains a crib, so the key is FULLY determined - no search, no freedom.
The decryption of the rest of the text is then a prediction.  If K4 is locally
periodic (a key that changes only at a boundary), the letters next to the run
must come out English.

==============================================================================
B3. Do the two crib runs imply the same periodic key?
==============================================================================
If one periodic key covered both runs we would already have a solution (it does
not - established).  But the DEGREE of agreement says whether a key change
between them is plausible: with a genuine shared period we would expect the two
independently derived keys to agree on many residues by accident of the data.

 Maximum agreement found is reported; chance is p/26 residues.)
