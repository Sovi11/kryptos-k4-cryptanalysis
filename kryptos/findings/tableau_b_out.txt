# (b) The tableau anomalies as key material

## B0. What the deviation actually is

physical row N (index 14): NGHIJLMNQUVWXZKRYPTOSABCDEFGHIJL
ideal    row N (index 14): NGHIJLMNQUVWXZKRYPTOSABCDEFGHIJ
=> exactly one inserted letter, 'L', at the end of that row.
linear index (0-indexed) in the 867-letter reading: 464
Because it is an INSERTION, physical[465:] == ideal[464:] exactly: True
So the 'sequence of deviations' has length 1.  Everything below is an attempt to
turn that single datum into a key stream, a period, or a position.

## Verdict for (b)

The physical-vs-ideal deviation set has cardinality ONE.  One bit of information
cannot be a 97-letter key stream, and every derived reading of it (the delta stream,
the numbers it names used as periods, its linear position used as a running-key
offset, its row and its column used as repeated key blocks) fails the cribs at the
chance level.  No survivor.
