## D2. K4-aligned label streams (exactly 97 letters, no offset freedom)

K4 occupies left-panel row 25 columns 28-31 and all of rows 26-28, 31 columns wide.
Opposite those cells the tableau carries rows X, Y, Z and the footer.  The ROW
LABEL and the COLUMN LABEL of each of those 97 cells are the two streams the brief
names.  Neither has any free offset, so each is a single 97-letter candidate.

  row-label stream : XXXXYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYZZZZZZZZZZZZZZZZZZZZZZZZZZZZZZZ???????????????????????????????

## D4. The same block-Hamming metric lateral/test_lateral.py uses

test_lateral.py slides the 13-letter EASTNORTHEAST key block and the 11-letter
BERLINCLOCK key block (42 apart) along each stream and reports the best Hamming
distance.  Its result on 73 non-tableau streams and 16.5M tests was: best block1
6/13, best block2 5/11, best JOINT 16/24, 0 hits within threshold.  Same metric,
same code path, applied to the tableau streams it never saw:

  tests 2,301,936
  best block1 Hamming : 6/13  ('carved body column-major', 'beaufort/pt=keyed/ct=keyed/key=plain', 4, 334)
  best block2 Hamming : 6/11  ('carved body column-major', 'varbeaufort/pt=keyed/ct=keyed/key=plain', 20, 61)
  best JOINT  Hamming : 16/24  ('carved body column-major', 'beaufort/pt=keyed/ct=keyed/key=plain', 4, 334)
  chance expectation: a random 24-letter window has mean Hamming 24*(25/26) = 23.08;
  P(joint Hamming <= 16) = 2.02e-06 for one window, so over 2,301,936 windows chance alone
  produces 4.7 windows at least this good.  Observed: >=1.  The best result here is
  the same joint 16/24 that lateral/test_lateral.py reached on its own 73 streams,
  which is what chance is supposed to deliver.  A solution is joint Hamming 0.
  P(block1 Hamming <= 6) = 1.74e-07 ; P(block2 Hamming <= 6) = 3.2e-05
