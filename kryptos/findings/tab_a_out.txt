## A2. What a one-element deviation list can possibly encode

An observer who knows the ideal tableau learns, from the carving, only:
  which position was altered : log2(867) = 9.76 bits
  which letter was inserted  : log2(26)  = 4.70 bits
  total                      : 14.46 bits
A 97-letter key stream carries 97*log2(26) = 456 bits.
A 24-letter crib fit demands 24*log2(26) = 113 bits of key information.

So the anomaly CANNOT BE the key: it is short of a 97-letter stream by a factor of
32, and short of even the crib block by a factor of 7.8.
The only cryptographically coherent roles left for it are SELECTOR roles -- it can
name a number (a period, an offset, a shift, a switch point) or flip a rule.  A3-A6
test every such role exhaustively.  This bound is why (a) can be CLOSED rather than
merely searched: the space of things one datum can select is small and finite.

## A5. The anomaly position as a SWITCH POINT where the rule changes

This is the only reading in which one datum can do real cryptographic work: it
names an index s at which the system changes behaviour.  The anomaly's own
candidate switch points, mapped into K4's 0..96 index range:
  s = 0   <- 97 (K4 length (for reference))
  s = 11  <- 11 (L is index 11 of the plain alphabet)
  s = 13  <- 13 (N is index 13 of the plain alphabet)
  s = 14  <- 14 (row N is the 14th lettered row (0-indexed), carved row 14 of 28); 402 (letters after the extra L)
  s = 15  <- 15 (row N is carved row 15 (1-indexed))
  s = 18  <- 18 (L is index 18 of the KRYPTOS alphabet)
  s = 26  <- 26 (rows in the tableau body (alphabet size))
  s = 30  <- 30 (ideal body-row width)
  s = 31  <- 31 (the extra L sits at column 31 (0-indexed) of its row)
  s = 32  <- 32 (carved row N is 32 characters long)
  s = 76  <- 464 (0-indexed linear position of the extra L)
  s = 77  <- 465 (1-indexed linear position of the extra L)
  s = 90  <- 866 (ideal tableau length)
  s = 91  <- 867 (carved tableau length)

Rather than test only those, every model below is swept over ALL 96 interior switch
points, so the anomaly-named ones can be scored against the best obtainable.

## A6. The PHASE-SLIP hypothesis

Motivation, and it is documented rather than invented: in April 2006 Sanborn
announced that he had OMITTED one ciphertext letter from K2, which threw the tail
of that message out of phase with its key and made the ending unreadable
(https://elonka.com/kryptos/CorrectedK2Announcement.html).  The tableau anomaly is
an INSERTED letter.  If a running key were drawn from the carved panel, an
insertion is exactly the defect that puts everything after it one place out.
So: running key from the tableau, with one letter deleted or duplicated at every
possible slip point, every offset, all 24 combos, all 26 rotations.
